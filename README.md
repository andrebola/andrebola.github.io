# andrebola.github.io

Personal website of [Andres Ferraro](https://andrebola.github.io).

Built with [Jekyll](https://jekyllrb.com/) and the [Indigo](https://github.com/sergiokopplin/indigo) theme, hosted on GitHub Pages.

## Local development

```bash
bundle install
bundle exec jekyll serve --config _config.yml,_config-dev.yml
```

Open [http://localhost:4000](http://localhost:4000) in your browser.
